# SaaSPro Landing Page

Сучасний, повністю адаптивний лендінг, розроблений для SaaS-продукту або IT-послуги. Створений за підходом Mobile-First, з використанням сучасних можливостей CSS (Grid/Flexbox) та інтерактивністю на чистому JavaScript.

## 🚀 Особливості проєкту

- **Семантичний HTML5 та CSS3:** Чистий код, який легко підтримувати, без використання громіздких фреймворків.
- **Адаптивний дизайн:** Ідеальне відображення на мобільних пристроях (320px+), планшетах та десктопних екранах.
- **Сучасна верстка:** Використання CSS Grid та Flexbox для побудови гнучкої сітки.
- **CSS змінні (Variables):** Зручне управління кольоровою гамою та типографікою з одного місця.
- **Vanilla JavaScript:** 
  - Інтерактивне мобільне бургер-меню.
  - Плавний скролл до розділів сайту.
  - Валідація форми на стороні клієнта (перевірка довжини імені та формату номера телефону).

## 💻 Як запустити локально

1. Склонуйте цей репозиторій на свій комп'ютер.
2. Перейдіть до директорії `landing-page`.
3. Відкрийте файл `index.html` у будь-якому браузері або скористайтеся розширенням типу Live Server у VS Code для запуску локального сервера.
