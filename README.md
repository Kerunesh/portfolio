# 🚀 Portfolio Projects

Привіт! Це мій робочий репозиторій, де зібрані реалізовані проєкти з автоматизації, парсингу даних, розробки Telegram-ботів та веб-верстки. 

## 📂 Структура репозиторію

Нижче наведено список проєктів. Кожен з них знаходиться в окремій папці з детальною інструкцією щодо запуску.

### 1. [Freelancehunt Bot](./freelancehunt-bot)
Telegram-бот для автоматичного моніторингу нових проєктів на біржі Freelancehunt. Бот фільтрує замовлення за заданими ключовими словами та категоріями, миттєво надсилаючи сповіщення, що дозволяє першим відгукуватися на вигідні пропозиції.

### 2. [Cleaning Service Calculator Bot](./cleaning_bot)
Інтерактивний Telegram-бот для клінінгової компанії. Працює як калькулятор послуг: клієнт обирає тип прибирання, площу та додаткові опції, після чого бот розраховує фінальну вартість і формує готову заявку для менеджера.

### 3. [E-commerce Web Scraper](./web-scraper)
Автоматизований скрипт для збору даних з інтернет-магазинів. Парсер збирає інформацію про товари (назви, ціни, наявність, характеристики) та автоматично експортує їх у структурований Excel-файл для подальшого аналізу.

### 4. [SaaS Landing Page](./landing-page)
Сучасний, адаптивний Landing Page (Mobile First) для презентації IT-продукту. Зверстаний на чистому коді без використання важких фреймворків. Включає інтерактивний Header, CSS-анімації та валідацію форм на Vanilla JS.

## 🛠 Стек технологій
- **Backend & Automation:** Python (aiogram, BeautifulSoup, requests, pandas).
- **Frontend:** HTML5, CSS3 (Flexbox/Grid, Variables), Vanilla JavaScript.
- **Tools:** Git, GitHub, VS Code.
