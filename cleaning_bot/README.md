# 🧹 Cleaning Service Calculator Bot

Telegram-бот, розроблений для автоматизації розрахунку вартості послуг клінінгової компанії та збору заявок (лідогенерації).

## 🚀 Функціонал
- **Калькулятор вартості:** Користувач вводить площу приміщення та обирає тип прибирання (підтримуюче, генеральне, після ремонту).
- **Додаткові послуги:** Можливість додати миття вікон, хімчистку меблів тощо з автоматичним перерахунком ціни.
- **Оформлення заявки:** Збір контактних даних клієнта (ім'я, телефон, адреса).
- **Сповіщення адміну:** Миттєва відправка сформованого замовлення менеджеру в Telegram.

## 🛠 Технології
- Python 3
- `aiogram` (асинхронна робота з Telegram API)
- Модульна архітектура (State Machine для покрокового збору даних)

## 💻 Як запустити
1. Встановіть залежності: `pip install -r requirements.txt`
2. Створіть файл `.env` та додайте токен вашого бота: `BOT_TOKEN=ваш_токен`
3. Запустіть скрипт: `python main.py`
