# 🧹 Cleaning Company Telegram Bot

Telegram-бот для клінінгової компанії. Дозволяє клієнтам швидко розрахувати вартість прибирання, обрати додаткові послуги та залишити заявку. Бот автоматично надсилає деталі замовлення менеджеру та зберігає їх у базу даних SQLite.

## 🚀 Функціонал
- Інтерактивне меню на базі Inline-кнопок (FSM).
- Динамічний розрахунок вартості залежно від площі та типу прибирання.
- Мульти-вибір додаткових послуг (миття вікон, холодильника тощо).
- Збір контактних даних (ім'я, телефон, бажана дата).
- Автоматичне сповіщення менеджера в Telegram.
- Збереження всіх заявок у локальну базу даних SQLite.
- Зручне налаштування цін через `config.json`.

## 🛠 Технології
- **Python 3.10+**
- **aiogram 3.x** (Асинхронний фреймворк для Telegram Bot API)
- **aiosqlite** (Асинхронна робота з базою даних)
- **python-dotenv** (Робота зі змінними оточення)
