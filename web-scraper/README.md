# 🕷️ E-commerce Web Scraper

Python-скрипт для автоматизованого збору інформації про товари з каталогів інтернет-магазинів та збереження даних у зручному форматі.

## 🚀 Функціонал
- **Екстракція даних:** Збір назв товарів, артикулів, поточних цін та посилань на зображення.
- **Пагінація:** Скрипт автоматично переходить по сторінках каталогу до повного збору потрібної категорії.
- **Експорт у Excel:** Зібрані дані формуються у зручну таблицю `.xlsx` за допомогою бібліотеки `pandas` для подальшого імпорту в CRM або аналізу.

## 🛠 Технології
- Python 3
- `BeautifulSoup4` / `requests` (парсинг HTML-коду)
- `pandas` / `openpyxl` (робота з даними та експорт у Excel)

## 💻 Як запустити
1. Встановіть необхідні бібліотеки: `pip install -r requirements.txt`
2. Відкрийте файл скрипта і вкажіть цільовий URL для парсингу (змінна `TARGET_URL`).
3. Запустіть скрипт: `python scraper.py`
4. Після завершення роботи у папці з'явиться файл `products_data.xlsx`.
