# E-Commerce Web Scraper & Аналітик Цен Конкурентів

Автоматизований Python-парсер для збору даних про товари з e-commerce майданчиків, автоматичного аналізу цін і знижок та формування стилізованих Excel-звітів для дослідження ринку.

## 🌟 Основні можливості

- **Багатосторінковий парсинг:** Ефективний обхід каталогу товарів із використанням `httpx` та `BeautifulSoup4`.
- **Валідація даних та аналітика:** Використання моделей `Pydantic` з обчислюваними полями для автоматичного розрахунку відсотка знижки (`discount_percent`).
- **Обхід блокувань та обробка помилок:** Підміна заголовків (`User-Agent`), налаштування таймаутів та безпечна обробка некоректних відповідей сервера.
- **Готовий бізнес-звіт в Excel:** Форматування за допомогою `pandas` та `openpyxl` (стилізовані заголовки, автопідбір ширини колонок, грошовий та відсотковий формати даних, межі комірок та автофільтр).

## 🛠 Технологічний стек

- **Мова:** Python 3.10+
- **HTTP-клієнт:** `httpx`
- **Парсер:** `BeautifulSoup4`, `lxml`
- **Обробка даних та моделі:** `pydantic` v2, `pandas`
- **Генерація та стилізація Excel:** `openpyxl`
